# Marvin's skills

Een verzameling skills voor Claude: ontwerp, schrijven, strategie, onderzoek en documenten.

- `skills/<slug>/` – één map per skill, met `SKILL.md` en eventuele hulpbestanden.
- `MANIFEST.md` – herkomst van elke skill (GitHub-bron, plugin of Claude-voorbeeld).

De collectie bestaat uit de skills uit de eerdere Paperclip-back-up (2026-10-12) aangevuld met de skills die in Claude (cloud) geïnstalleerd zijn (2026-10-23), o.a. `impeccable`, `marvin-strategie-style`, `code-reviewer`, `deep-research`, `workshop-ontwerper` en `skill-creator`.

Skills van derden behouden hun oorspronkelijke licenties (zie de LICENSE-bestanden in de betreffende mappen en de bronnen in `MANIFEST.md`).
