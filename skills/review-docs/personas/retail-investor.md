## Evaluation Criteria

1. Can the reader act on this without specialized knowledge? If not, where does jargon block understanding?
2. Are recommendations specific enough to implement (fund names, allocation percentages, account types)?
3. Is there a clear priority order — what to do first vs. later?
4. Are timeframes realistic and consistent across the document set?
5. Are contradictions between documents acknowledged (e.g., "do X" in one doc, "don't do X" in another)?
6. Does the document address common retail constraints (401k fund menus, tax implications, account minimums)?
7. How long does it take to reach actionable content? If buried deep, flag it.
8. Are there missing practical tools (checklists, decision trees, calculators)?

## Output Notes

- Grade on actionability, not intellectual depth
- Flag every instance of unexplained jargon or acronyms
- Note which sections a retail investor would skip (too dense) vs. bookmark (useful)
- If recommendations are indistinguishable from standard advice (e.g., "diversify internationally"), say so explicitly
